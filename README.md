# 🛒 E-commerce Website

A **responsive e-commerce website** built using **HTML, CSS, and JavaScript**, featuring a modern UI, product catalog, shopping cart functionality, and a fully responsive design.

🔗 **Live Demo:** [ecommerce_website.tiiny.site](https://ecommerce_website.tiiny.site/)

---

## 🚀 Features

* 📱 **Responsive Design** – Works seamlessly across desktops, tablets, and mobile devices
* 🛍️ **Product Catalog** – Displays featured products and new arrivals
* 🛒 **Shopping Cart Icon** – Add products to cart (frontend demo)
* ⭐ **Product Ratings** – Star ratings for better UI/UX
* 🎨 **Modern UI** – Clean and attractive layout with banners, features, and offers
* 📧 **Newsletter Signup** – Email subscription form
* 🔗 **Footer with Quick Links** – About, My Account, Socials, Install App
